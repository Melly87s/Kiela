# Security Policy

## Supported Versions

Only the latest official Kiela release is supported.
Please update before reporting a problem.

Official releases:
https://github.com/Melly87s/Kiela/releases/latest

## Reporting a Vulnerability

If the Security tab provides a "Report a vulnerability" option,
use it to report security issues privately.

Otherwise, open an issue requesting a private contact method.
Do not include exploit details, passwords, or personal information
in public issues.

Include the affected version, a description of the problem,
and steps to reproduce it through the private reporting channel.

Reports are reviewed as maintainer availability permits.
No fixed response or resolution time is guaranteed.

Official project: https://github.com/Melly87s/Kiela
