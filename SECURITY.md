# Security Policy

## Supported Versions

Only the latest official Kiela release is supported.
Please update before reporting a problem.

Official releases:
https://github.com/Melly87s/Kiela/releases/latest

## Reporting a Vulnerability

If the Security tab provides a "Report a vulnerability" option,
use it to report security issues privately.

Otherwise, open an issue requesting a private contact method.
Do not include exploit details, passwords, or personal information
in public issues.

Include the affected version, a description of the problem,
and steps to reproduce it through the private reporting channel.

Reports are reviewed as maintainer availability permits.
No fixed response or resolution time is guaranteed.

## Authorship and License Protection

It is strictly prohibited to claim Kiela's original filter code,
rules, recommendations, descriptions, or documentation as your
own work.

Do not remove required author credits, rename the filter to
present it as your own creation, or present a modified version
as an official Kiela release.

Use, modification, and redistribution are governed by
[LICENSE-KIELA.md](LICENSE-KIELA.md).

Third-party contributions retain their original licenses and
attribution requirements. This policy does not claim exclusive
ownership of public game data, facts, mechanics, or filter syntax.

Report suspected unauthorized appropriation through the official
repository, including links to the original material and the copy.

Official project: https://github.com/Melly87s/Kiela
