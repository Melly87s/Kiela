# Kiela Filter v1.2.36

Original Kiela presentation and class-aware recommendations for Project Diablo 2,
building on the third-party work acknowledged in THIRD-PARTY-NOTICES.md.

Official project: https://github.com/Melly87s/Kiela

## Install

1. Download **[Kiela Filter.filter](./Kiela%20Filter.filter)** using GitHub's Raw / Download raw file control.
2. Save it in your Diablo II installation's `ProjectD2/filters/local` folder.
3. In the PD2 launcher, open **Item Filter Profiles**, select **Local Filter**,
   choose **Kiela Filter.filter** and save the selection.
4. Start the game and choose the strictness level you want.

The filter is a normal PD2 text filter. No generator, Node.js, activation key,
custom loader, font modification or separate program is required to play.
Listing in the launcher's online filter catalog requires separate registration;
creating this GitHub repository alone does not add it to that catalog.

## Features

- Original item-quality colors and compact, graded symbol accents.
- Automatic player-class runeword recommendations; matching names are green.
- Druid recommendations are tuned for Summon; builds are not automatically detected.
- Socket recipes, roll ratings and available market estimates in item descriptions.
- Explicit potion recovery numbers, colored gems and progressive base filtering.

This is a softcore ladder market-price snapshot, not a live in-game market connection.
Prices are estimates and may become stale; exact-stat charm coverage is limited.
Ratings indicate tracked roll quality, not guaranteed sale value.
